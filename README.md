# 🎓 Student Grade Tracker

A professional Java console-based application developed for **CodeAlpha Java Programming Internship - Task 1**.

## 📌 Project Description

The Student Grade Tracker is a Java application that allows users to manage student records, calculate grades, and generate academic reports. It is developed using Object-Oriented Programming (OOP) concepts and Java Collections.

## ✨ Features

- Add Student Details
- View All Students
- Search Student by ID
- Update Student Marks
- Delete Student Record
- Calculate Average Marks
- Assign Grades Automatically
- Display Highest & Lowest Average
- Generate Statistics Report
- Display Class Ranking
- Generate Final Academic Report
- Console-Based User Interface

## 🛠 Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner Class
- Exception Handling

## ▶️ How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Compile the project:

```bash
javac Student.java StudentManager.java Main.java
```

4. Run the application:

```bash
java Main
```
